4. Le redimensionnement auto des champs (`field-sizing: content`)

Date d'introduction : Début 2024

Explication

Tout développeur web a un jour écrit un script JavaScript fastidieux pour écouter l'événement input d'un <textarea> et ajuster sa hauteur en temps réel. La propriété field-sizing: content permet aux inputs et textareas de s'adapter automatiquement à leur contenu de manière totalement native.

Démo Live

Code CSS

.auto-resize-textarea {
  field-sizing: content;
  min-height: 3lh;
  max-height: 10lh;
  width: 100%;
}

.auto-resize-input {
  field-sizing: content;
  min-width: 5ch;
  max-width: 100%;
}

Compatibilité et Fallback

Fallback : Il s'agit d'une amélioration progressive. Sur un navigateur non compatible, le champ texte adoptera son comportement classique : une taille fixe par défaut avec l'apparition d'une barre de défilement (scroll) si le texte dépasse. L'interface reste totalement utilisable.
