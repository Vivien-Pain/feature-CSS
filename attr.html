1. La fonction attr() avancée avec typage

Date d'introduction : Fin 2024 (Chrome 129+)

Explication

Historiquement, la fonction attr() était extrêmement limitée : elle ne pouvait renvoyer que des chaînes de caractères et ne s'utilisait qu'avec la propriété content des pseudo-éléments. La nouvelle spécification révolutionne cela en permettant de "typer" la donnée récupérée (ex: type(<color>) ou type(<length>)). On peut ainsi utiliser un attribut HTML classique pour définir dynamiquement une largeur, une couleur de fond, ou n'importe quelle propriété CSS, sans avoir recours aux variables CSS inline !

Code CSS

.attr-box {
        background-color: #334155; /* Fallback si attr() n'est pas supporté */
        background-color: attr(data-color type(<color>), #334155);
        width: 100%;
        width: attr(data-width type(<length-percentage>), 100%);
}

Compatibilité et Fallback

Fallback : Si le navigateur ne supporte pas le typage dans attr(), la déclaration entière est ignorée. Il faut donc déclarer une valeur par défaut juste au-dessus. De plus, la fonction intègre nativement son propre fallback (le deuxième paramètre) qui s'applique si l'attribut HTML est manquant ou invalide.
