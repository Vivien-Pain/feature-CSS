7. Les dégradés animés (Houdini @property)

Date d'introduction : 2024

Explication

En CSS classique, il est impossible d'animer un dégradé de couleur (background gradient) car le navigateur ne comprend pas la notion mathématique d'angle, il ne voit que du texte. L'API @property permet de "typer" une variable personnalisée en tant qu'angle (<angle>), permettant ainsi au moteur d'interpolation du navigateur de l'animer de 0deg à 360deg.

Démo Live

Carte Premium

Code CSS

@property --angle {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}

.houdini-card::before {
  background: conic-gradient(from var(--angle), #ff007f, #3b82f6, #10b981, #ff007f);
  animation: spin-gradient 3s linear infinite;
}

@keyframes spin-gradient {
  to {
    --angle: 360deg;
  }
}

Compatibilité et Fallback

Fallback : Amélioration progressive parfaite. Sur un ancien navigateur qui ne comprend pas @property, l'animation sera ignorée, mais le dégradé s'affichera correctement de manière statique à 0 degré (l'initial-value ne sera juste pas animée).
